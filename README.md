# BILIM PLAY

Қазақ тіліндегі білім беру ойын платформасының алғашқы MVP прототипі.

## Іске қосу
GitHub Pages немесе Cloudflare Pages арқылы жариялау үшін репозиторийдің түбіріндегі `index.html` файлын пайдаланыңыз. Build қадамы қажет емес.

## MVP мүмкіндіктері
- 12 ойын форматының каталогы
- Мұғалімге арналған ойын құрастыру беті
- Пән, сынып және ойын түрін таңдау
- Сұрақтар мен 4 жауап нұсқасын енгізу
- Дұрыс жауапты белгілеу
- Браузерде ойын сақтау (`localStorage`)
- Алдын ала көру, ойын режимі және ұпай санау

## Келесі кезең
Firebase Authentication, Realtime Database, PIN-кодпен ойын бөлмелері, оқушылардың қосылуы және командалық жарыс.
